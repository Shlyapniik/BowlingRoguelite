# 3D Roguelite Prototype

A 3D top-down roguelite prototype built with **Unity and C#**.

The player controls a rolling ball and fights waves of enemies in a small low-poly world. During a run, the player gains experience, unlocks upgrades and becomes stronger. Earned coins can be used between runs to improve the character permanently.

## Gameplay

* Wave-based enemy combat
* Player movement based on a rolling ball
* Experience and level-up system
* Random upgrades during a run
* Orbital weapons and other player abilities
* Enemy spawning and progression
* Permanent upgrades between runs
* Procedural gameplay elements
* Cinemachine camera
* Unity NavMesh enemy navigation
* Health and damage systems

## Tech Stack

* **C#**
* **Unity**
* Unity NavMesh
* Cinemachine
* Unity UI
* Git / GitHub
